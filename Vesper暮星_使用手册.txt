Vesper 暮星 · 简明使用手册
适用版本：Vesper-6.1

Vesper 暮星可以在游玩过程中翻译 Unity 游戏文字，并提供图片文字识别、游戏库管理和离线数值修改工具。

注意：目前支持部分 Mono、IL2CPP 游戏，但不是所有 Unity 游戏都能兼容。

一、打开软件

将完整的软件运行包解压到文件夹，打开 Vesper暮星.exe。

不要只把 exe 单独拿出来，其他文件也需要保留。GitHub 上的 Source 源码包供开发使用，不能直接双击运行。

二、添加游戏

进入“游戏翻译”页面，将以下任意一种内容拖到游戏库区域：
1. 游戏本体的 .exe 文件。
2. 包含游戏本体的文件夹。

也可以使用页面上的添加按钮。

如果提示找不到游戏，请确认拖入的是游戏本体，而不是快捷方式、安装程序或单独的启动器。

三、选择翻译服务

进入左侧“翻译服务”页面。

方式一：免费翻译

选择“免费翻译”中的“必应 Bing”，然后点击“保存并启用”。
不需要填写 API 密钥。

受必应供应商及网络影响，首次翻译预计需要等待约 30 秒，也可能更久。免费通道可能出现限流或暂时不可用。

方式二：API 翻译

按照服务商提供的信息，填写接口地址、模型名称和 API 密钥，再点击“保存并启用”。

API 是否收费、翻译速度如何，取决于你选择的服务商。

重要：修改翻译服务后，需要重新启动游戏才会生效。

四、启动翻译

回到“游戏翻译”页面：
1. 在游戏库里选中游戏。
2. 打开“联网翻译”。
3. 点击游戏下方的主要按钮。

按钮会根据游戏状态显示：
- 安装翻译组件：游戏第一次使用翻译功能。
- 一键更新并启动：游戏内的翻译组件需要更新。
- 启动游戏：组件已准备好，可以直接开始。

首次安装完成后，按提示启动游戏。游玩期间请保持 Vesper 运行。

五、识别图片文字

有些文字画在图片里，普通文字翻译无法直接读取。这时可以尝试开启“识别图片文字”。

软件会根据游戏和当前环境判断支持情况；如果开关不可用，请查看旁边的说明。

使用覆盖式识图翻译时，建议将游戏设置为窗口化或无边框窗口。过小、模糊、花体或快速变化的文字，可能无法准确识别。

六、管理游戏和使用数值工具

游戏库中可以重命名游戏、打开所在文件夹，或移出游戏库。

“移出游戏库”只删除列表记录，不会删除游戏、存档或已安装的翻译组件。

如果需要移除翻译组件，先退出游戏，再到“组件管理与详情”中选择“卸载翻译组件”。

“数值工具”是独立的可选功能，不影响正常翻译。以查找金币为例：
1. 启动游戏，并在数值工具中确认已连接。
2. 输入当前金币数量，点击“首次查找”。
3. 回游戏让金币数量发生变化。
4. 输入新的数量，点击“再次查找”。
5. 逐步缩小结果，确认地址后再修改。

仅用于你有权修改的离线游戏，操作前建议备份存档。它不是完整版 Cheat Engine。

七、遇到问题怎么办？

问：游戏没有翻译？
答：确认“联网翻译”已开启、翻译服务已保存，并通过 Vesper 启动游戏。如果刚修改过服务，请退出游戏后重新启动；首次使用免费翻译需要等待。

问：普通文字翻译了，图片文字没翻译？
答：检查“识别图片文字”是否开启、当前游戏是否支持，并尝试窗口化。部分复杂图片文字仍可能无法识别。

问：有些内容始终保持原文？
答：可能是游戏兼容性、字体、文字布局或识别能力的限制，不代表整个翻译功能都失效了。

第一次使用记住这条顺序就够了：
添加游戏 → 设置翻译服务 → 保存并启用 → 安装或更新组件 → 启动游戏。
